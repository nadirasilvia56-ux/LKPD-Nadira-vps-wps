Fase 1: Pengenalan Konsep VPS & Cloud

1. Shared Hosting

Layanan hosting di mana satu server fisik dibagi dan digunakan bersama-sama oleh banyak pengguna/website. Sumber daya (CPU, RAM, Storage) dikelola bersama, berbiaya murah, namun performa dapat terpengaruh oleh aktivitas website lain dan akses konfigurasi server sangat terbatas.

2. Dedicated Server

Layanan server fisik utuh yang disewa secara eksklusif oleh satu pengguna tanpa dibagi dengan orang lain. Menawarkan performa maksimal, kontrol penuh (full root access), dan tingkat keamanan tinggi, tetapi dengan biaya sewa yang jauh lebih mahal.

3. Amazon Lightsail

Layanan VPS pemula dari AWS yang menyediakan server virtual mandiri dengan harga tetap dan terjangkau. Sangat mudah digunakan untuk deployment aplikasi sederhana, website, atau lingkungan pengembangan (development) tanpa harus pusing mengatur konfigurasi jaringan yang rumit.

4. Amazon EC2 (Elastic Compute Cloud)

Layanan server virtual (instance) berskala enterprise dari AWS yang menawarkan fleksibilitas penuh untuk mengatur kapasitas komputasi, sistem operasi, dan jaringan sesuai kebutuhan aplikasi skala besar dengan sistem pembayaran pay-as-you-go (bayar sesuai penggunaan).
